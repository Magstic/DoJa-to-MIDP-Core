# DoJa MIDP Tools

DoJa to MIDP 時的建置工具。

```text
classfile     class file 解析與 bytecode 改寫
translation  TSV 與 class 文字處理
image        GIF 解碼與圖片正規化
jam          JAM 與 MIDP metadata
scratchpad   Scratchpad 與音訊轉換
font         FontUsage、按需 Shift-JIS mapping 與位圖字形
verify       產物檢查
io           檔案 I/O
```

模組功能與公共 API 請見： [ARCHITECTURE.md](ARCHITECTURE.md)。
